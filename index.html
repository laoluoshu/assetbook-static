关于资产簿
一款帮你记录现金、固定资产、投资与负债，按月存档、用图表展示变化、按配置方案对照目标并估算净值排位的个人资产管理工具。
· 这是静态单页版：不用注册登录、不联网，双击 index.html 也能直接记账；数据存于本浏览器 localStorage，不上传任何服务器。
· 换设备或换浏览器时，用「导出 JSON 备份 → 导入」搬运；清理浏览器数据会一并清除账本，建议定期导出。
· 净值 = 现金 + 固定资产 + 投资 + 保险 + 债权 − 负债。
· 采用三级结构?：一级分类（可自定义）→ 二级小类（如「建行活期」「自住房产」，同名可有多处）→ 变动记录（记录每月增减）。小类当前值 = 变动记录累计和，再汇总到一级分类供图表与规划使用
· 投资类支持填写本金，自动按当前市值计算回报。
· 规划页内置标普家庭资产象限、4321 法则及保守/平衡/激进分型等国际通用配置参考，可自由增删改方案，并与实际资产做对比。
· 金额按变动记录逐条累加，界面与备份文件一律以「元」呈现。
备份说明
· JSON 是完整备份：含全部二级小类与变动记录、自定义分类、配置方案、概览背景图与字号设置，用于换设备/换浏览器时完整还原，也兼容原版 v1.19 导出的备份文件。
· CSV 仅含记录明细（月份/一级分类/二级小类/变动金额/备注），适合用 Excel 查看，不能用于还原。
· 导入为覆盖式：会替换当前浏览器里的全部业务数据，操作前会二次确认。
· 备份文件的金额单位为「元」，与界面显示一致，可直接用文本编辑器查看。
