# 资产簿 · 静态单页版

一款帮你记录现金、固定资产、投资与负债的个人资产管理工具 —— **纯静态、零依赖、不需要服务器**。
所有数据保存在你自己的浏览器里（localStorage），不上传任何服务器，不联网也能用。

**在线使用：<https://laoluoshu.github.io/assetbook-static/>**

> 这是「资产簿」的单机版。另有带账号同步、AI 建议的在线版（Cloudflare Workers + D1），
> 两个版本的数据可以通过「导出 JSON 备份 → 导入」互相搬运。

## 功能

- **三级结构**：一级分类（可自定义）→ 二级小类（如「建行活期」「自住房产」）→ 按月变动记录
- **概览**：净资产 / 总资产 / 总负债 / 环比，近 6 月净值趋势，各分类当前值
- **图表**：资产构成饼图、含负债的分类进度条、任意两月对比（分类明细 + 图表）
- **记录**：按月 / 按分类查看，投资类支持记录本金、自动算回报
- **规划**：内置标普「1234」、4321 法则、保守 / 平衡 / 激进分型，可自由增删改，规划 vs 实际对比
- **排位**：净资产分位估算（内置示例基准，仅供娱乐参考）
- **数据管理**：JSON 完整备份 / 还原（覆盖式）、CSV 明细导出、按范围清空、示例数据
- **个性化**：全局字号缩放、概览背景图（自动压缩后本地保存）

## 使用注意

- **数据只存在当前浏览器的 localStorage 里**：换设备 / 换浏览器不会自动同步；
  清理浏览器数据（或用无痕模式）会清掉账本。请定期「设置 → 导出 JSON 备份」。
- 直接双击 `index.html` 也能用，部署只是方便随处访问。
- 备份文件为 JSON（带 `type: assetbook-backup` 标识），兼容在线版导出的备份。

## 开发 / 部署

无构建步骤、无外部依赖（图表为原生 Canvas 自绘），目录即站点：

```
index.html      页面结构
css/style.css   样式（米色手账风，移动端自适应）
js/api.js       本地数据层（localStorage，接口与线上版 /api/* 一一对齐）
js/app.js       页面逻辑
js/charts.js    Canvas 图表（折线 / 饼图 / 对比柱）
js/ui.js        基础组件（对话框 / Toast / 格式化）
```

部署到 GitHub Pages：把内容推到 `gh-pages` 分支，仓库 Settings → Pages 源选择 `gh-pages` 即可。

## 隐私

不联网、不埋点、无第三方请求。你的资产数据、背景图、偏好设置全部只存在于本机浏览器。
